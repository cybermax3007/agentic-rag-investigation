# CaseFile AI

Interactive Agentic RAG Investigation system built for the 180DC ML recruitment task.

## Case Corpus

The project currently uses Arthur Conan Doyle's
"The Adventure of the Norwood Builder"
from Project Gutenberg's public-domain edition of
"The Return of Sherlock Holmes".

## Architecture

The project will contain:

- FastAPI backend
- Hybrid lexical + semantic retrieval
- Evidence graph
- Investigator Agent
- Fact-Checker Agent
- Candidate interrogation
- Streamlit frontend
